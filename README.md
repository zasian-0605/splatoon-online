# スプラ3風 Web v28 FUN PACK

v27安定版を土台に、ゲーム本体を壊さない形で遊びごたえを追加した版です。

## 追加
- 試し撃ちの30秒TARGET RUSH（動くターゲット6体 / 15ヒット目標）
- ヒット演出、コンボ、SPボーナス
- 発射時の軽い反動とマズルフラッシュ
- 対戦開始演出
- 120秒 INK RUSH（SPがたまりやすい）
- 60秒 CLUTCH TIME（短時間の移動速度UP）
- 残り30秒 FINAL SPLASH告知
- 低HP時の画面警告
- リロード/モード移動後に練習ターゲットを持ち越さないクリーンアップ
