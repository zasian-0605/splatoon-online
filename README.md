## 📌 現在のゲーム

- 2〜8人のルーム制オンライン対戦
- 同じ部屋の全員が「準備OK」になったら、その人数で対戦開始
- 複数ルームを同時に作成可能
- 名前＋パスワードの新規登録 / ログイン
- WEBランク、レート、勝敗、試合数を保存
- ロビー・ラジオ・施設・試し撃ち
- 高低差のある3Dステージ
- インクによる移動・壁登りなどのゲームシステム
- 複数のブキ・サブ・スペシャル

## 🛠️ 開発環境

ゲーム本体は `index.html` を中心に構成されています。

Renderでは以下で動作します。

- Build Command: `npm install`
- Start Command: `npm start`
- Runtime: Node.js

HTML/JavaScriptの検証には `npm run validate` を使用できます。

## ⚠️ 注意

このプロジェクトはSplatoonを題材にしたファンメイドのWebゲームです。任天堂およびSplatoon公式とは関係ありません。
