# スプラ3風 Webオンライン v12

学校側の端末にゲーム用アプリをインストールせず、ブラウザだけで遊ぶための構成です。

## できること
- 試し撃ち場：自由移動・射撃・各武器・ギアなどをそのまま利用
- CPU対戦：4vs4
- オンライン：最大8人、4vs4自動振り分け
- PCでもスマホ/タブレット系ブラウザでも、公開URLを開いて参加可能

## 公開Web版
1. このフォルダをGitHubへアップロード
2. RenderなどのNode.js Web Serviceへ接続
3. Build Command: `npm install`
4. Start Command: `npm start`
5. 発行された `https://...` のURLを全員がブラウザで開く

オンライン通信は同じURLのWebSocket (`wss://...`) を自動使用します。

## 家のPCでローカル確認
Node.jsが入っている開発PCで:

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開くと、試し撃ち・CPU対戦を含むゲーム全体を確認できます。オンラインは同じサーバーへ接続します。

## 注意
学校のネットワークが外部ゲームやWebSocketを制限している場合、学校の管理者の許可が必要です。ネットワーク制限を回避する設定は行わないでください。

- Pointer Lockで試し撃ち/CPU対戦中のマウス視点を中央固定。ドラッグ不要。
- Mキーでミニマップを拡大表示。試し撃ち・CPU・オンラインで表示。


## v12 追加
- スーパージャンプ：フルマップで味方をタップして味方の位置へ移動
- PCでは 1 / 2 / 3 でも味方を選択可能
- iPad/タッチ端末向けに MAP ボタンを追加

※この版のHTMLはThree.jsを外部CDNから読み込むため、完全オフライン動作はまだ保証していません。

### v16: 自作3Dロビー
Blenderや外部3Dモデルを使わず、Three.jsのプリミティブとコード生成テクスチャだけでロビー街を生成。中央広場、高層ビル、商店、路地、高架、ネオンサイン、NPC、4つの施設入口を追加。ロビーから試し撃ち・CPU 4vs4・オンライン8人・カスタマイズへ移動できます。
