# Splatoon-like Web v79

v25を基準にした安定版。ゲーム本体は `index.html` 1ファイルです。`server.js` はオンライン通信・ルーム・アカウント保存用です。

## 主な変更
- 2〜8人のルーム制オンライン対戦
- 同じ部屋の全員が「準備OK」になったら、その人数で対戦開始
- ルームごとに最大8人なので、複数ルームを同時に作成可能
- 名前＋パスワードの新規登録 / ログイン
- WEBランク、レート、勝敗、試合数を保存
- オフライン（`file://`）では同一端末のローカルアカウントを利用
- v25のロビー・ラジオ・施設・試し撃ちの処理を基準として維持
- 分割された `town.html` / `battle.html` は使用しません

## Render
Build Command: `npm install`
Start Command: `npm start`

### アカウントデータについて
サーバー版では `data/accounts.json` に保存します。パスワードは平文ではなく、Node.jsのscryptでハッシュ化します。

Renderの通常のファイルシステムはデプロイ・再起動・スピンダウンで消えるため、長期間残す本番用データにはRender Postgresなどの永続データストアが必要です。無料Web Serviceだけで試す場合、同じインスタンスが動いている間の保存として使ってください。
