## 🌟 このプロジェクトについて

**Splatoon Online** は、Splatoonのインクを使ったバトルゲームの楽しさを参考にした、個人開発のWebゲームプロジェクトです。

HTML / CSS / JavaScript / Three.js / Node.jsを使って、ブラウザ上の3Dゲームとオンライン対戦を開発しています。

このプロジェクトの目標は、ゲームを完成させるだけではありません。

**「遊ぶ人」と「作る人」が一緒にゲームを育てる開発所**を目指しています。

Fork → 修正 → Pull Request の流れで変更を提案できます。

## 🧭 開発の流れ

```text
🎮 遊ぶ
  ↓
🐛 バグ発見 / 💡 アイデア
  ↓
GitHub Issue
  ↓
💻 修正・開発
  ↓
Pull Request
  ↓
レビュー
  ↓
mainへ反映
  ↓
🌐 公開版を更新
```

Issueで問題や提案を共有してから大きな変更を始める、という流れを基本にしています。GitHubもIssueとPull Requestを使った共同開発を推奨しています。

## 🎮 現在のゲーム

- 2〜8人のルーム制オンライン対戦
- 準備完了したメンバーで対戦開始
- 複数ルーム対応
- ログイン / アカウント機能
- WEBランク・レート・勝敗・試合数
- ロビー・施設・試し撃ち
- 高低差のある3Dステージ
- インクを利用した移動・壁登りなどのシステム
- 複数のゲーム内ブキ・サブ・スペシャル
- PC / モバイル向け操作への対応を開発中

## 🛠️ 技術

- HTML / CSS / JavaScript
- Three.js
- Node.js
- npm
- Render

ゲーム本体は主に `index.html`、オンラインサーバーは `server.js` を中心に構成されています。

### ローカル開発

```bash
npm install
npm start
```

検証スクリプト：

```bash
npm run validate
```

## 📜 更新履歴

### v79
- 通常射撃を水平発射に統一

- スロッシャーの着弾範囲ダメージをオンライン側にも反映
- ローラー・ブラシの向きをカメラ照準と統一
- ストリンガー3本射撃をクライアント・サーバーで同期
- ブキID 0〜44をサーバー側でも認識
- 床・高台・壁の見た目の塗りを `paintInk()` に集約
- HTML構文検証スクリプトを修正し、`npm run validate` を追加

### v80
- Three.js r128をnpm依存（three@0.128.0）に変更
- 外部cdnjsへの依存を削減
- ブラウザ側は `/node_modules/three/build/three.min.js` を同一Renderサービスから読み込む
- 既存の高低差・AIナビゲーション・3Dインク・オンライン同期を保持
